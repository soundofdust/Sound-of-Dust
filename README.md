# Sound-of-Dust
Sound of Dust (Shawt at-Turab - صوت التراب) adalah ruang kritik dan opini tentang negara, hukum, agama, ormas, dan hal-hal yang menyentuh hidup bersama. Terinspirasi dari debu: tampak remeh, tapi suci dan menyucikan, membuat orang berhenti sejenak dan memperhatikan sekitar. Ditulis warga biasa, berpijak pada data, terbuka dikoreksi.
